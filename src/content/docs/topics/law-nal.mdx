## 不正アクセス禁止法 (要点)

### 禁止行為 (3+1 類型)

| 条文 | 行為 | 罰則 |
| --- | --- | --- |
| 3条 | **不正アクセス行為** (他人の ID/PW で侵入、セキュリティホール攻撃) | 3 年以下/100万円以下 |
| 4条 | 識別符号の **不正取得** | 1 年以下/50万円以下 |
| 5条 | 不正アクセスの **助長行為** (ID/PW を提供) | 1 年以下/50万円以下 |
| 6条 | 識別符号の **不正保管** | 1 年以下/50万円以下 |
| 7条 | **フィッシング** (識別符号入力を求める偽メール/サイト) | 1 年以下/50万円以下 |

<div class="sc-key">
試験で問われるのは「**未遂は罰されない**」「**個人ベース** で適用 (法人は対象外)」という点。
被害届を出すのはアクセス管理者 (アクセス制御を実装している側)。
</div>

### 不正アクセス行為の定義

<Mermaid code={`flowchart TD
  A[アクセス制御機能のある<br/>特定電子計算機] --> Q{どの行為?}
  Q -->|他人の<br/>識別符号入力| B[不正アクセス成立]
  Q -->|セキュリティホール<br/>攻撃| C[不正アクセス成立]
  Q -->|認証回避コマンド| D[不正アクセス成立]
  E[アクセス制御なし] --> F[不正アクセスに該当しない]
  style B fill:#ffd6d6
  style C fill:#ffd6d6
  style D fill:#ffd6d6
  style F fill:#d6f5d6
`} />

<div class="sc-trap">
**アクセス制御機能がない** 公開 Web サイトを荒らしても不正アクセス禁止法には該当しない (別の罪に問われる可能性あり)。
午後で「ログイン不要のフォームで攻撃された」場合、適用は不正アクセス禁止法ではなく、**業務妨害罪** や **不正指令電磁的記録罪** が候補。
</div>

## 刑法 (電子計算機関連犯罪)

| 条文 | 罪名 | 典型例 |
| --- | --- | --- |
| 168条の2 | **不正指令電磁的記録作成罪** (ウイルス作成罪) | マルウェア作成・提供・取得・保管 |
| 234条の2 | **電子計算機損壊等業務妨害罪** | DDoS、改ざんによる業務停止 |
| 246条の2 | **電子計算機使用詐欺罪** | 不正送金、ポイント不正搾取 |
| 161条の2 | 電磁的記録不正作出罪 | 改ざん証跡作成、不正な口座操作データ |

<div class="sc-key">
**サイバー攻撃 = 不正アクセス禁止法だけ** ではない。攻撃の **結果** によって複数の罪が同時に成立する
(不正アクセス + 電子計算機使用詐欺、など)。
</div>

## 不正競争防止法 (営業秘密)

営業秘密の 3 要件 (試験頻出):

<Mermaid code={`flowchart LR
  A[営業秘密の3要件] --> B[秘密管理性<br/>アクセス制限・秘密表示]
  A --> C[有用性<br/>事業活動に有用]
  A --> D[非公知性<br/>一般に知られていない]
  B & C & D --> E[営業秘密として保護]
  style E fill:#d6f5d6
`} />

<div class="sc-trap">
**秘密管理性** が一番落ちやすい。「マル秘」表示や ACL 制御がなく、社員誰でも見られる状態だと
「秘密として管理されている」と認められず、漏えいしても法的保護を受けられない。
</div>

## サイバーセキュリティ基本法

- 内閣に **サイバーセキュリティ戦略本部** を設置
- **NISC** (内閣サイバーセキュリティセンター) が事務局
- 重要インフラ事業者は **対策状況の報告** が求められる
- 教育・人材育成・研究開発の推進

<div class="sc-key">
試験頻出: 「重要インフラ」13 分野 (情報通信・金融・航空・空港・鉄道・電力・ガス・政府・行政・医療・水道・物流・化学・クレジット・石油)。
正確に列挙する必要は薄いが、**重要インフラ事業者には NISC 経由の情報共有義務がある** ことは押さえる。
</div>

## プロバイダ責任制限法

匿名のネット投稿で権利侵害 (誹謗中傷など) を受けた被害者が、**発信者を特定できる仕組み**。

<Mermaid code={`sequenceDiagram
  autonumber
  participant V as 被害者
  participant CP as コンテンツプロバイダ<br/>(SNS)
  participant AP as アクセスプロバイダ<br/>(ISP)
  participant 加害者 as 加害者
  V->>CP: 発信者情報開示請求 (IP+時刻)
  CP->>V: IP アドレス開示
  V->>AP: 発信者情報開示請求 (IP→契約者)

  AP->>V: 契約者情報開示
  V->>加害者: 損害賠償等
`} />

令和 4 年改正で **裁判所への 1 回の手続で開示まで進める** 制度ができ、特定までの時間が短縮された。

## 特定電子メール法

「広告又は宣伝のため」のメール送信を規制。

- **オプトイン原則** (事前同意のあるアドレスにのみ送信可)
- 表示義務: 送信者氏名、苦情受付窓口、配信停止 URL
- 違反は **総務大臣の措置命令** + 罰則

## 確認問題

<details class="sc-answer">
<summary>Q1. 同僚から共有された会社の ID/PW で、業務時間外に許可されていないシステムにアクセスした。不正アクセス禁止法違反になるか。</summary>

**A.** **なる**。アクセス管理者の利用許諾なく他人の識別符号を用いて利用権限を超える行為は不正アクセス。
「同僚から教えてもらった」は正当化にならない。
</details>

<details class="sc-answer">
<summary>Q2. 自社で営業秘密として管理していたつもりの設計書が漏えいした。不正競争防止法上、保護されるための条件は何か。</summary>

**A.** **秘密管理性 / 有用性 / 非公知性** の 3 要件を満たすこと。
特に秘密管理性は ACL/「マル秘」表示/NDA 等の **客観的な管理実態** が必要。
</details>

<details class="sc-answer">
<summary>Q3. ランサムウェア感染で業務が停止した場合、攻撃者に適用されうる罪を 2 つ。</summary>

**A.** 不正指令電磁的記録 (ウイルス) 関連罪、電子計算機損壊等業務妨害罪。
身代金要求があれば恐喝罪、暗号化解除と引き換えに金銭を得れば電子計算機使用詐欺罪も。
</details>
