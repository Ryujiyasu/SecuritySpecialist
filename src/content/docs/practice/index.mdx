## 類似テストとは

IPA の過去問とは別に、**本番に近い形式**で作成した独自の演習問題集です。
過去問を周回した後の**仕上げ**や、過去問の論点で**応用力を試す**目的で使ってください。

## 利用方法

1. **時間を計って解く** (大問 1 問につき 45〜60 分目安)
2. **解答用紙を印刷** または別紙に手書きで答案作成
3. 模範解答と照合
4. 「私の答案 vs 模範」の差分を [午後問題対策](/SecuritySpecialist/afternoon/writing/) を参照して分析

## 類似テスト作成ポリシー

- IPA の出題傾向 (R3〜R7) を分析し、頻出論点を組み合わせて作問
- 問題文には **固有条件** を散りばめ、一般論で逃げない訓練ができる構成
- 設問は **理由 / 対策 / 問題点 / 具体名** をバランス良く配置
- 模範解答は **採点ポイントと頻出誤答** を併記

## 著作権
