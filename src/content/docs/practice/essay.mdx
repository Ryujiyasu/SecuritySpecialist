SC 午後問題の **記述式答案** を Gemini（Google の生成 AI）が採点・添削します。
答案を入力 → AI が **点数 / 良かった点 / 改善点 / 模範解答例 / キーワード抜け** をフィードバック。

:::note[使い方]
1. **Google サインイン**（メールアドレスのみ取得。サインインは API 不正利用防止のため必須）
2. 設問を読んで、指定字数で答案を記述
3. **「AI 添削をリクエスト」** をクリック → 数秒で結果が表示されます
:::

:::caution[AI 添削の注意]
Gemini の採点は **学習の目安** です。本試験の正答とは異なる場合があります。
模範解答や試験官の採点基準と照らし合わせて、参考としてご活用ください。
:::

<EssayGrader
